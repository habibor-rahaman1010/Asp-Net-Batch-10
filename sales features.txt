4. STOCK RESERVATION
--------------------------------------------------

When a Sales Order is confirmed, support stock reservation.

Example:

Reserved = 30
Available = 70

Do not directly reduce physical stock when reserving.

Maintain distinction between:
- OnHand
- Reserved
- Available

Available = OnHand - Reserved

When an order is cancelled, reserved stock must be released.

When goods are delivered:
- Reserved stock decreases
- OnHand stock decreases

Reuse the existing Inventory/Stock transaction system if available.
